ARSITEKTUR & LOGIKA PROGRAMMER

Antisipasi "Masalah Teknis" di Lapangan

Sesuai dokumen perencanaan Tri Hardian Siregar, halaman ini mendemonstrasikan bagaimana kode program menangani 3 kejadian tak terduga saat website digunakan di Bengkel TI SMK N 1 Binjai.

SKENARIO 1

Rebutan Stok Terakhir (Database Lock)

Masalah: Laptop tinggal 1 unit (LAPTOP-03). Di detik yang sama, Budi dan Andi sama-sama klik tombol "Pinjam" dari HP mereka.

Solusi Koding: Kunci data sementara (Mutex / Atomic Lock). Siapa yang masuk duluan walau selisih 0,01 detik, dia yang dapat. Yang kedua ditolak otomatis.

// Klik tombol di atas untuk menguji Database Lock...
SKENARIO 2

Balikin Barang Dicicil (Loan Details)

Masalah: Siswa meminjam 1 Laptop dan 2 Tang Crimping. Besoknya dia baru mengembalikan Laptopnya saja, tangnya masih dipakai.

Solusi Koding: Memisahkan tabel loans (header transaksi) dan loan_details (rincian per item), sehingga pengembalian dicatat per barang beserta kondisinya (Baik/Rusak).

Data Demo Siap Uji:
Transaksi milik Siti Aminah (XII TKJ 1) memiliki 1 unit LAPTOP-01 dan 2 Tang Crimping yang siap dicicil pengembaliannya.
SKENARIO 3

Blokir Otomatis Rekan Nunggak

Masalah: Siswa masih memiliki tanggungan alat yang belum dikembalikan (apalagi sudah telat), tapi mencoba meminjam alat lain.

Solusi Koding: Validasi otomatis pada checkBorrowerEligibility(). Selama masih ada item berstatus dipinjam/telat, tombol pinjam dikunci.

Data Demo Siap Uji:
Akun Rizky Pratama (XI TKJ 2) memiliki pinjaman Multimeter Digital yang berstatus TELAT.

Cara Upload ke GitHub & Aktifkan GitHub Pages

Aplikasi ini dirancang 100% Static Single-File sehingga tidak membutuhkan server PHP/MySQL untuk dijalankan secara online.

  1. Simpan kode aplikasi ini dengan nama file index.html.
  2. Buka GitHub.com dan klik New Repository (misal beri nama: peminjaman-bengkel-ti).
  3. Klik uploading an existing file, lalu seret file index.html dan klik Commit changes.
  4. Masuk ke tab Settings → Pages pada repositori tersebut.
  5. Pada bagian Branch, pilih main dan folder / (root), lalu klik Save.
  6. Tunggu ±1 menit, link website live Anda akan muncul dan siap dipresentasikan!
